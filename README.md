# Algora — Interactive DSA Visualizer

**Algora** is an interactive web application designed to help developers and students visualize how Data Structures and Algorithms (DSA) work under the hood. Instead of memorizing dry pseudocode, beginners can input their own custom values and watch every step, pointer movement, and comparison play out in real time.

### What You Can Visualize
* **Linear Data Structures:** Stack, Queue, and Linked Lists
* **Non-Linear Data Structures:** Trees and Graphs
* **Core Algorithms:** Searching and Sorting techniques with step-by-step breakdowns
* **Custom Input Testing:** Enter your own inputs and edge cases to see exactly how each algorithm handles them
